# 🎙️ Uji Coba Suara Cuking di ElevenLabs (gratis)

Tujuan: memilih **satu suara** yang paling cocok untuk Cuking **sebelum membayar**.
Paket gratis ElevenLabs berisi ±10.000 karakter per bulan. Uji coba ini hanya memakai ±4.000 karakter.

---

## Langkah 1: Buat akun gratis
1. Buka **elevenlabs.io** → **Sign up**. Bisa langsung masuk dengan akun Google.
2. Pilih paket **Free**. Tidak perlu memasukkan kartu.

## Langkah 2: Cari 3 kandidat suara
1. Buka menu **Voices** → **Explore** (Voice Library).
2. Pakai filter **Language: Indonesian**.
3. Cari suara dengan kata kunci **cheerful**, **friendly**, **storyteller**, atau **young**. Suara perempuan muda yang ceria biasanya paling disukai anak.
4. Dengarkan contohnya, lalu tekan **Add to my voices** untuk **3 suara** yang paling Anda sukai.

## Langkah 3: Buat suara dari naskah uji
1. Buka menu **Text to Speech**.
2. Pilih salah satu kandidat suara.
3. Pilih model **Eleven v3**, lalu atur **Stability** ke **Natural** atau **Creative**, supaya suaranya lebih ekspresif.
4. Salin **Naskah B** di bawah, tempel, lalu tekan **Generate**.
5. Ulangi untuk kandidat suara ke-2 dan ke-3.
6. Opsional: coba juga **Naskah A** dengan model **Eleven Multilingual v2** pada suara favorit, sebagai pembanding.

> Kata dalam kurung siku seperti `[excited]` adalah **petunjuk emosi** untuk model Eleven v3. Kata itu tidak ikut dibacakan.

---

## Naskah A: tanpa petunjuk emosi
*(untuk model Eleven Multilingual v2)*

```
Meong! Halo teman! Aku Cuking, si kucing. Ayo kita belajar sambil bermain!
Hewan apa yang bunyinya, guk, guk, guk?
Hore, benar! Ini anjing. Bunyinya, guk, guk, guk!
Itu kambing. Tidak apa-apa, coba lagi ya!
Ada berapa balon? Ayo kita hitung! Satu, dua, tiga, empat, lima!
Mana huruf be? Be, Bola!
Tut tuuut! Keretanya berangkat!
Hore! Kamu hebat sekali! Kamu dapat lima bintang! Mau main lagi?
```

## Langkah 4: Nilai dan pilih
Dengarkan hasilnya, idealnya bersama satu atau dua anak, lalu beri nilai 1–5:

| Yang dinilai | Suara 1: ______ | Suara 2: ______ | Suara 3: ______ |
|---|---|---|---|
| Terdengar seperti manusia, tidak kaku | | | |
| Ceria dan ramah anak | | | |
| Logat Indonesia, tidak kebarat-baratan | | | |
| Pelafalan jelas (nama "Cuking", "be", angka, "guk guk") | | | |
| Saat anak salah, nadanya lembut dan menyemangati | | | |
| **Total** | | | |

## Langkah 5: Kirim hasilnya ke saya
Kirimkan:
1. **Nama suara** pemenangnya.
2. **Voice ID** suara tersebut. Caranya: buka **Voices** → **My voices**, klik suara itu → salin **ID**-nya.
3. **Model** yang lebih bagus: **Eleven v3** atau **Multilingual v2**.
4. Catatan kalau ada kata yang salah ucap, misalnya "Cuking" terdengar aneh.

⚠️ **Jangan kirim API key ke siapa pun**, termasuk lewat chat. API key baru dibutuhkan setelah berlangganan, dan nanti Anda sendiri yang memasukkannya ke file di laptop.
